
HLD और LLD की तुलना

• HLD (High-Level Design)
	• यह 'बिग पिक्चर' (बड़ी तस्वीर) दिखाता है।
	• इसमें यह तय होता है कि कौन-कौन सी सेवाएं (Services) आपस में कैसे बात करेंगी।
	• यह स्केलेबिलिटी (Scalability) और सिक्यूरिटी जैसी बड़ी चीजों पर ध्यान देता है।
	• इसके लिए ब्लॉक डायग्राम या आर्किटेक्चर फ्लो बनाए जाते हैं।
• LLD (Low-Level Design)
	• यह HLD के बाद बनाया जाता है।
	• यह हर एक मॉड्यूल को बारीक स्तर पर खोलता है।
	• इसमें डेटाबेस की टेबल्स, इनपुट-आउटपुट वैलिडेशन और एरर हैंडलिंग तय होती है।
	• यह सीधे कोड लिखने में डेवलपर्स की मदद करता है।

### centralized vs distributed system
Centralized system mein saara data aur processing ek single main server par hoti hai, jabki distributed system mein multiple independent computers ek network par milkar kaam karte hain aur resources share karte hain.
